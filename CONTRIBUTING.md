# Contributing to Digit AI

Thank you for your interest in contributing to **Handwritten Digit Recognition using Deep Learning**.

We welcome improvements, bug fixes, documentation updates, UI enhancements, and new ideas.

## How to Contribute

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/BlockNotes-4515/Handwritten-Digit-Recognition.git

git checkout -b feature/your-feature

streamlit run app.py

git add .
git commit -m "Add: your feature"
